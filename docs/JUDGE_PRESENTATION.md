# SentinelX — Judge Presentation

## Pitch arc (5 minutes)

1. **Hook (0:00–0:30)** — "Every enterprise is one pasted prompt away from leaking its crown jewels. SentinelX sits between users and the LLM and makes leaking impossible."
2. **The problem (0:30–1:00)** — real examples: AWS keys, salary sheets, patient records going into public models. Regulators (GDPR/HIPAA/PCI) care.
3. **The 8-agent pipeline (1:00–2:00)** — run **/demo** in Judge mode. Let it self-narrate through all 6 attacks.
4. **Explainability (2:00–2:30)** — open an incident: why, how, which rule, confidence, alternative outcome. "Black-box AI is dead."
5. **Enterprise readiness (2:30–4:00)** — quick tour: executive score, SOC threat feed, org twin, analytics brush-zoom, copilot, settings.
6. **Close (4:00–5:00)** — download the protection report, confetti fires, "6 attacks. 0 leaks. 1 platform."

## Judge Presentation Mode

`/demo → Enter judge mode` transforms the page:

- **Hides developer controls** (scenario chips collapse).
- **Larger typography** (headers and stats scale up).
- **Faster animation** (0.55× pacing).
- **Narration captions** — an auto-updating subtitle explains each stage.
- **Presentation timer + progress** — always visible.
- **Auto-scroll** — panels follow the action.
- **Confetti + report** — a triumphant close.
